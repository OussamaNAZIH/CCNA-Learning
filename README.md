## 📖 About

This repository documents my journey toward the **Cisco Certified Network Associate (CCNA 200-301)** certification.

It includes:

- 📚 Personal notes
- 🧪 Packet Tracer labs
- ⚙️ Cisco IOS configurations
- 🔍 Troubleshooting guides
- 📈 Learning progress

My goal is to build a solid networking foundation for a future career in **Cloud Engineering** and **Cloud Security**.
